# Repeated screen composition and asset evidence

Date: 2026-10-14. Owning authorities: SPEC §7-2, ONTOLOGY_CONTRACT and
AGENTCORE_CONTRACT. This source delivery does not establish service activation.

The ontology workbench selects an accepted B0 source analysis, its current
admitted collection, any document admissions needed by the selected Screens,
and approved Screen revisions. A source analysis retains its immutable manifest
and consumed admissions after job TTL. The workflow rejects local/legacy
producer records, changed analysis bytes, withdrawn sources and resolver changes.

The current canonical context supplies approved `IMPLEMENTS` witnesses from
code files/exports to Screens. Static mining counts files; reusable proposals
also count distinct exact approved Screens. Multiple files for one Screen cannot
meet independent repeat support. Unmapped identities, unresolved dependencies,
dynamic composition and bounded/truncated mining remain visible. Excess scope
fails before paid work rather than trimming the accepted request.

`design.derive` shares the registered knowledge completion adapter and existing
context/generate/verify protocol. One inspected, measured model call proposes
title/intent text. Counts, citations, relations, template slots and review state
come from independently repeated deterministic mining, never model assertions.
The verifier rejects missing/duplicate/unknown proposal IDs, malformed metadata,
invented numerical literals and insufficient independently reviewed support.
It never invents a template's executable code interface.

Completion atomically stores a private proposal and its signed evidence. Human
adoption rechecks exact artifact version/result hash, canonical generation,
every source/admission predicate, expiry and current project membership.
It publishes candidates only. Subsequent UX node approval and independent
reference regeneration retain their owning interfaces.

The asset detail view separates wireframe blocks, GUI snapshot declaration and
code declaration. It links a GUI to a current matching asset original and blocks
missing bindings. It lists registered usage witnesses and revision/hash
bases. Declared layer presence is not a three-layer acceptance receipt.
