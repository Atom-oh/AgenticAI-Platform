# Architecture and workflow decisions

Accepted decisions apply only to their stated scope. A later decision must name
the earlier decision it supersedes. Historical plans are supporting evidence,
not implicit ADRs.

| Decision | Status | Scope |
|---|---|---|
| [ADR-001: Shared documentation authority](ADR-001-documentation-authority.md) | Accepted | Agent context and PR review |
| [ADR-002: Project workbench](ADR-002-project-workbench.md) | Accepted for initial implementation | Knowledge, impact, Skills and business workspace |
| [ADR-003: Ontology AgentCore execution](ADR-003-ontology-agentcore-execution.md) | Accepted for implementation sequencing; activation gated | Canonical authority, dedicated execution and platform integration |

For current product requirements, use `SPEC.md`; for evidence and document
precedence, use [review context](../REVIEW_CONTEXT.md).
