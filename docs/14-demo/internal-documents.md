# 내부 문서함과 원문 기반 영향 분석

규정 영향 분석에서 문서 이름만 보는 대신, **분석에 사용한 버전의 원문과
근거 문단**을 직접 열 수 있다. 문서를 등록하고 승인한 뒤 분석하는 순서다.
아래는 저장소에 구현된 사용 흐름이며, 운영 배포와 계정 권한은 별도 확인한다.

## 1. 원문 등록

1. 로그인하고 왼쪽 **내부 문서함**을 연다.
2. **문서함 범위**에서 개인 문서함 또는 참여 프로젝트를 선택한다.
3. **새 문서 등록**을 누르고 PDF, HTML, Markdown 또는 TXT 파일을 선택한다.
   파일당 최대 20 MiB다.
4. 제목과 문서 종류를 입력한다. 영향 분석에 연결하려면 **관계 목록의 연결 대상**에서
   해당 규정 또는 문서를 선택한다. 버전 이름과 시행일도 기록할 수 있다.
5. **원문 전송** 후 본문 추출 결과를 확인한다.

HTML은 실행하지 않고 글을 추출한다. 스캔 이미지, 암호화 PDF, 지원하지 않는
시각 요소 등으로 본문을 온전히 확인할 수 없으면 분석용 승인이 제한된다.
원본 파일은 보관되며 **원본 내려받기**로 확인할 수 있다.

PNG·JPG·SVG 같은 화면 디자인 자산의 반입은 [디자이너 작업실](./studio-designer-guide)의
파일 반입 흐름을 사용한다. 내부 문서함은 업무 규정과 명세의 본문 근거를 관리한다.
외부 문서 URL을 자동으로 따라가 내용을 가져오지 않는다.

## 2. 검토와 권한

추출된 본문을 원본과 대조한 뒤 검토를 요청한다. 소유자 또는 기획 담당자는
확인 항목과 의견을 작성하고 해당 버전을 승인하거나 반려한다.
등록만으로 승인되거나 AI 입력에 포함되지는 않는다.

프로젝트 문서의 읽기 권한은 소유자가 역할별로 설정한다. 문서 조회, 원본 다운로드,
분석 실행과 저장된 결과 조회에서도 현재 접근 권한을 확인한다.
분석 기록은 요청자가 자신의 문서함 범위에서 조회한다.

**새 버전 등록**은 이전 원본과 검토 기록을 남긴다. 새 승인본이 생기면 기존 분석은
당시 근거를 유지하되, 최신 원문으로 다시 분석하기 전에는 새 판단을 저장할 수 없다.

## 3. 영향 후보에서 근거 확인

1. **규정 영향 분석**에서 같은 문서함 범위를 선택한다.
2. 규정과 질문을 선택하고 분석을 요청한다.
3. **검토 요약**, **분석에 사용한 승인 원문**, **영향 후보**를 확인한다.
4. 문서 링크는 분석 당시 원문 버전을 연다. 근거 문단 링크는 해당 버전의 특정
   문단을 열고 강조한다. 원문을 바꿔 끼워 링크를 복구하지 않으며,
   접근 권한이나 확인값이 맞지 않으면 오류를 표시한다.
5. **분석 결과로 돌아가기**로 복귀하고, 권한이 있는 담당자가 후보별 판단과 의견을
   저장한다.

승인된 규정 원문이 없으면 모델을 호출하지 않고 원문 연결이 필요한 상태와 관계에 따른
후보를 보여준다. 일부 문서만 연결됐거나 일부 문단만 입력에 포함됐으면 그 범위를 표시한다.
AI가 제시한 인용 ID가 존재한다는 확인은 해석이 맞다는 증명이 아니다.
AI 의견과 사람이 기록한 수정 판단은 별도로 표시한다.

## 예제로 살펴보기

**합성 예제 구성 보기**를 누르면 문서를 등록하기 전에도 종류, 용도와 **포함 내용 보기**를
확인할 수 있다. 아래 7종은 담보 기준 변경 시 각 문서가 어떤 검토에 쓰이는지 설명하는 예제다.

| 합성 문서 | 포함된 검토 내용 |
|---|---|
| 전세자금대출 담보 인정 기준 | 상품 조건·고객 안내·화면·컴포넌트가 같은 변경 범위를 따르는지 검토 |
| 전세자금대출 담보 인정 기준 개정 기안 | 변경 사유·대상 조항·변경 전후 설명과 협의 근거 기록 |
| 전세대출 상품 심의 보고 | 담보 기준과 상품 설명의 일치 여부 및 조건 차이 검토 |
| 전세대출 화면 변경 요청 | 입력 항목·안내 문구·조건 분기·컴포넌트와 필요한 동작 검증 확인 |
| 담보 인정 비율 리스크 점검 | 상품 적용 범위와 조건 영향 검토. 실제 금융 수치는 포함하지 않음 |
| 전세대출 영업점 시행 공문 | 승인된 변경 내용·적용 대상·시행 시점·문의 담당자 확인 |
| 전세대출 취급 교육 자료 | 변경 기준·화면 안내·업무 절차의 교육 자료 반영 여부 확인 |

미리보기는 문서함의 등록·승인 상태를 뜻하지 않는다. 실제 등록 문서는 왼쪽 목록에서 선택한다.
소유자는 **합성 예제 7종 새로 등록**으로 테스트 자료를 만들 수 있다.
예제는 자동 승인되지 않으며, 원문과 설명을 확인하고 필요한 문서만 직접 검토한다.
예제 원본 교체는 지원하지 않으므로 별도 자료는 새 문서로 등록한다.

원문을 열면 제목·문서 종류와 **이 문서는 무엇인가요?** 안내를 확인할 수 있다.
안내는 원본 파일의 확인값까지 일치하는 합성 예제에만 표시한다.
근거 문단으로 바로 이동해도 해당 문서의 제목·종류·버전을 함께 보여주며,
원문 문단과 링크의 확인값을 바꾸지 않는다.

현재 연결 대상은 **공유 시연 관계 목록**이다. 합성 문서는 실제 은행 내규가 아니며,
고객사의 규정·상품·담당부서 관계망을 연결한 것으로 해석해서는 안 된다.
최초 시연에는 합성 자료를 사용한다.

## 실패 모드

| 표시 또는 상황 | 확인·복구 방법 |
|---|---|
| 본문 일부만 추출됨·추출 실패 | 원본을 내려받아 확인하고, 본문을 지원하는 형식으로 새 버전을 등록한다. 불완전한 추출본을 승인하지 않는다. |
| 승인된 원문 없음 | 같은 문서함 범위에서 규정·문서 연결 대상을 확인하고 원문을 등록·검토한다. |
| 접근 권한 확인 실패 | 참여 프로젝트와 문서의 읽기 권한을 담당자에게 확인한 뒤 다시 조회한다. |
| 분석 당시 원문이 변경됨 | 기존 근거는 당시 버전으로 읽고, 판단 저장은 최신 승인본으로 다시 분석한 뒤 수행한다. |
| 인용 연결·AI 응답 표현 검사 실패 | 제외된 AI 의견을 확정 판단으로 사용하지 않는다. 원문과 영향 후보를 직접 검토하거나 새 분석을 요청한다. |
| 원문 확인값 불일치 | 다른 버전으로 대신 열지 않는다. 정확한 반입 버전과 보관 파일을 담당자에게 확인한다. |
