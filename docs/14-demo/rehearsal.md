# 시연 리허설 — 15분 스크립트와 체크리스트

시연 URL: <https://agent.atomai.click/> · 계정은 시연 운영자에게 확인.
시작 전 좌측 하단 배지 확인: **그래프 백엔드 = Neptune Serverless**, **PII 추론 경로 배지(운영 IDC GPU+vLLM / 데모 Gemma 대체)**.

## 오프닝 (30초)

> "말로 하면 반박당하는 세 가지를 화면으로 증명하겠습니다 — ① 벡터 RAG만으로는 부족하다,
> ② 개인정보는 프라이빗 경계 안에 두고 모델 호출만 익명화해서 내보낼 수 있다,
> ③ 사내 AI 자산은 Git처럼 승인 관리되어야 한다."

대시보드에서 **Single Boundary 지표**(경계 통과 토큰·사용 모델 ID·차단 여부 — 전부 실측)를 먼저 짚는다 — "15분 뒤에 다시 봅니다."

## S1 — 규정 영향 분석 (4분)

1. 레일 "규정 영향 분석" → **시나리오 S1** 버튼 → **동시 실행**.
2. 좌측(Vector RAG)이 먼저 끝난다 → *"정확한 규정 청크를 찾았지만 '관련 문서를 정비하라' 수준입니다. 비교군을 약화시키지 않았습니다 — BM25+임베딩 하이브리드에 리랭커까지 정상 구현입니다."*
3. 우측(GraphRAG) → seed 신뢰도 배지 → counts 칩(상품 12·화면 39·부서 7·문서 7) → **근거 검증 통과** 배지: *"인용된 노드 ID 전부가 실제 순회 결과에 존재합니다 — 환각 0건."*
4. 하단 그래프에서 노드 하나 클릭(이웃 강조) → 더블클릭으로 온톨로지 탐색기 진입 → 노드 클릭으로 관계 확장 한 번.

핵심 멘트: *"같은 질문, 같은 모델 — 차이는 데이터의 구조입니다. 이것이 AI-Ready 데이터입니다."*

## S2 — 마이데이터 상담 (4분)

1. "마이데이터 상담" → **시나리오 S2** 버튼.
2. 단계 패널을 위에서부터 펼친다: ③ 조회된 원본 값(PII VPC) → ④ 계산엔진 **수식 단계**(우대 상한 min(0.7, 0.6) 짚기) → ⑤ 익명화 게이트 패널의 **기본 표시된 실제 전달 페이로드**(v2는 토글이 아니라 기본 노출): *"고객 식별자가 전부 토큰입니다. 경계 통과 PII 실측 0건."*
3. 우측 설명 완료 후 **수치 검증 통과** 배지: *"LLM이 숫자를 하나라도 지어내면 여기서 걸립니다."*

핵심 멘트: *"숫자는 LLM이 만들지 않습니다. 계산엔진이 만들고, LLM은 설명만 합니다."*

## S3 — Registry 반전 (3분)

1. "Agent Registry"에서 Button v2/v3 승인 상태 확인 → "화면 생성"에서 여신 심사 결과 화면 생성(승인 컴포넌트 목록 + 검증 게이트 결과 확인).
2. Registry에서 **Button v2를 Deprecated로 전환** → 재생성 → 코드가 v3 기반으로 바뀌는 것을 diff로 보여준다.

핵심 멘트: *"승인 상태가 결과를 바꿉니다. 사내 AI 자산 거버넌스가 장식이 아니라 실행 경로라는 뜻입니다."*

## S4 — Single Boundary 뷰 (2분)

- 방금 실행한 S1·S2가 타임라인에 쌓여 있다: traceId · VPC 잔류 항목 · 경계 통과 토큰 · **사용 모델 ID(global claude / gemma)** · Guardrails 판정 (§8-3 지표 5종).
- 배지 확인: *"저장: 서울 리전 / 추론: global 라우팅 — 그래서 익명화가 필수이고, 방금 요청들의 경계 통과 내역이 전부 실측으로 남았습니다."*

## S5 — Guardrails 차단 (2분)

- "마이데이터 상담"으로 돌아가 **S5 차단 시연** 버튼: "어떤 상품이 제일 돈 많이 벌어요?" → 실물 Bedrock Guardrails 차단 메시지.
- Guardrails 로그 뷰에서 차단 이력 확인. *"목이 아니라 실제 Guardrails입니다 — 시뮬레이션 금지가 요구사항이었습니다."*

## 클로징 (30초)

가이드북 탭(또는 [인터랙티브 아키텍처](https://www.atomai.click/AgenticAI-Platform/platform-architecture.html) Play story) → *"이 모든 통제는 저희 가이드북 93개 챕터의 설계 원칙 그대로이며, 아키텍처는 라벨만 바꾸면 IDC 병행 배치로도 동일하게 갑니다."*
